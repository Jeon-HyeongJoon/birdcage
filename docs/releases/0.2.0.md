# Birdcage 0.2.0

서명·공증 없이 개인용으로 사용하는 Premiere Pro CEP 확장 배포판입니다. Windows x64와 macOS 설치 파일에는 Birdcage Helper와 FFmpeg·ffprobe가 포함되어 있습니다. yt-dlp와 Deno는 패널 최초 실행 시 체크섬을 검증해 설치합니다.

## 다운로드 및 설치

### Windows x64

1. `Birdcage-Windows-x64-0.2.0.zip`을 내려받아 압축을 풉니다.
2. `install.cmd`를 실행합니다. 관리자 권한은 필요하지 않습니다.
3. Premiere Pro를 다시 시작하고 `창 > 확장 > Birdcage` 또는 `Birdcage 다운로드 목록`을 엽니다.

### macOS

1. `Birdcage-macOS-0.2.0.zip`을 내려받아 압축을 풉니다.
2. 터미널에서 압축을 푼 폴더로 이동해 `bash install.command`를 실행합니다.
3. Premiere Pro를 다시 시작하고 `창 > 확장 > Birdcage` 또는 `Birdcage 다운로드 목록`을 엽니다.

더블클릭한 서명 없는 설치 스크립트는 Gatekeeper가 막을 수 있으므로 macOS에서는 터미널 실행을 기본으로 합니다. Apple Silicon에서 번들 FFmpeg를 실행하려면 Rosetta가 필요하며, 네이티브 FFmpeg가 이미 설치되어 있으면 그 실행 파일을 우선 사용합니다.

## 주요 변경

- 링크 확인 화면과 다운로드 기록 화면을 분리하고 다운로드를 백그라운드 작업으로 전환했습니다.
- 메인 화면에서 현재 다운로드 시작 여부와 진행률을 바로 확인할 수 있습니다.
- 다운로드 완료·실패 기록을 두 패널과 Windows 환경에서도 공유합니다.
- 유튜브 검색과 현재 영상 기반 탐색 목록을 추가했습니다.
- 넓은 패널에서는 탐색 목록을 오른쪽에, 좁은 패널에서는 미리보기 아래에 배치합니다.
- CEP 10에서 한글 검색 결과가 표시될 때 발생하던 글꼴 탐색 지연을 제거했습니다.
- Windows 최초 도구 설치의 Deno 체크섬 판독 문제를 수정했습니다.
- macOS 설치기는 파일별 격리 속성을 제거하고 Helper·FFmpeg 실행을 확인합니다.
