# 0009. 원칙 SSOT와 생성된 AGENTS.md

- 상태: 초안 (2026-10-02)
- SSOT: `specs/principles.json`(원칙) + `loop/policy.json`(파라미터) → `AGENTS.md`(생성), `CLAUDE.md`는 `@AGENTS.md` import
- 실행 가능한 전제: P-0009-a, P-0009-b

## 결정
- 작업(W)·루프(L)·에이전트(A) 원칙을 기계가 읽는 명세로 둔다. 원칙마다 강제 수단(loopctl 규칙·전제·게이트·정책 키)을 명시하고, 아직 자동화되지 않은 부분은 honor/partial로 정직하게 표시한다.
- `loopctl check`(R-principle-refs)가 모든 참조가 실재하는지, 상태 표기가 참조와 일치하는지 검사한다.
- 에이전트가 세션마다 읽는 `AGENTS.md`는 SSOT에서 결정적으로 생성한다. 근거 문장은 넣지 않아 고정 접두를 짧고 안정적으로 유지한다(캐시 친화, 원칙 A7).

## 근거
- 해석 차이는 버그다: 사람용 문장만 있으면 에이전트마다 다르게 해석한다(사용자 원칙 "Interpretation Variance Is A Bug").
- 설명만 있는 문서 대신 실행 가능한 지식: 원칙 → 강제 장치 연결을 검사로 보장.
- 프롬프트 캐시 읽기는 입력 단가의 0.1배, 고정 접두가 같아야 맞는다.

## 재검토 조건
- honor 비율이 줄지 않을 때(자동화 백로그 점검), 다른 에이전트 도구가 AGENTS.md 외 형식을 요구할 때.
